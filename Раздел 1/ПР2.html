В этой версии эмулятора работают только базовые команды, которые есть в любой Linux-системе «из коробки».

  • whoami — имя пользователя.
  • pwd — текущая папка.
  • uname -a — информация о ядре.
  • id — ID пользователя и группы.
  • ls — список файлов.
